# Auto Bet — Σύστημα Στατιστικής Ανάλυσης Στοιχήματος

Αυτόματο σύστημα που αναλύει αγώνες ποδοσφαίρου μέσω API-Football και στέλνει
προβλέψεις σε **12 κανάλια Telegram, ένα ανά τύπο market**, όταν εντοπίζει
στατιστική ευκαιρία.

## Αρχιτεκτονική (ενημερωμένη Αύγουστος 2026)

- **Χωρίς Live** — μόνο pre-match ανάλυση
- **Κυλιόμενο παράθυρο ελέγχου**: κάθε `MARKET_CHECK_INTERVAL_HOURS` (default 3)
  ώρες, ελέγχει αγώνες που ξεκινούν μέσα στις επόμενες τόσες ώρες
- **12 κανάλια, ένα ανά market** (`config.BET_TYPE_CHANNELS`) — κάθε πρόβλεψη
  πηγαίνει στο δικό της κανάλι, χωρίς να "ανταγωνίζεται" άλλα markets για μία θέση
- **Αποτέλεσμα με επεξεργασία μηνύματος**: όταν τελειώσει ο αγώνας, το πρόγραμμα
  **επεξεργάζεται** το ίδιο μήνυμα προσθέτοντας ✅ ΚΕΡΔΙΣΕ / ❌ ΕΧΑΣΕ στο τέλος
  (όχι νέο μήνυμα)

## Κύμα 1 (ενεργό τώρα) — 6 markets σε 5 κανάλια

| Market | Κανάλι |
|---|---|
| 1-Χ-2 (Home/Draw/Away Win) | `1x2` |
| G/G & N/G (BTTS) | `gg_ng` |
| O/U Τερμάτων | `ou` |
| Κόρνερ | `stats_agona` |
| Κάρτες | `stats_agona` |
| Anytime/First Σκόρερ | `eidika_paikton` |

## Κύμα 2 (επόμενο βήμα) — νέα μοντέλα προς κατασκευή

DNB, Διπλή Ευκαιρία, Η/Τ, Ακριβές Σκορ, Σύνολο Γκολ (εύρος), Ασιατικό
Χάντικαπ, Ειδικά Ομάδων, Combo Bets (συνδυασμός 2 markets ίδιου αγώνα).
Τα κανάλια γι' αυτά υπάρχουν ήδη στο `config.BET_TYPE_CHANNELS`, απλά δεν
έχουν ακόμα συνδεδεμένο μοντέλο ανάλυσης.

## Κριτήρια ποιότητας

- Πιθανότητα: ελάχιστο 55% (στόχος 60%)
- Απόδοση: ελάχιστο 1.20, **χωρίς** ανώτατο όριο
- Edge (πλεονέκτημα έναντι αγοράς): ελάχιστο 5%

## Δομή αρχείων

| Αρχείο | Τι κάνει |
|---|---|
| `config.py` | Όλες οι ρυθμίσεις (κανάλια, ώρια, συχνότητες) |
| `api_football.py` | Κλήσεις προς το API-Football, με caching + budget guard |
| `league_classifier.py` | Αυτόματη ταξινόμηση λιγκών σε tier1/tier2/cups/διεθνή |
| `analysis.py` | Το στατιστικό μοντέλο (Poisson goal model) |
| `odds_parser.py` | Μετατρέπει raw odds response σε απλό dict, προτιμά ελληνικές στοιχηματικές |
| `telegram_sender.py` | Στέλνει/επεξεργάζεται μηνύματα |
| `sent_tracker.py` | Μνήμη ώστε να μην ξαναστέλνει το ίδιο δύο φορές |
| `results_tracker.py` | Παρακολουθεί εκκρεμείς προβλέψεις προς επεξεργασία αποτελέσματος |
| `scorer_matcher.py` | Ταίριασμα ονομάτων παικτών (fuzzy matching) |
| `main.py` | Ο scheduler loop — το πρόγραμμα που τρέχει συνέχεια |

## Πώς να το ανεβάσεις στο GitHub

1. Πήγαινε στο repo σου στο GitHub (web browser)
2. **Add file → Upload files**
3. Σύρε μέσα ΟΛΑ τα αρχεία αυτού του φακέλου
4. **Commit changes**

## Πώς να το στήσεις στο Render

1. Render Dashboard → **New +** → **Background Worker**
2. Συνδέσε το GitHub repo σου
3. **Build Command:** `pip install -r requirements.txt`
4. **Start Command:** `python main.py`
5. **Environment** (Settings → Environment):
   - `API_FOOTBALL_KEY` = το κλειδί σου
   - `TELEGRAM_BOT_TOKEN` = το token του bot σου
6. **Create Background Worker**

## Πρώτος έλεγχος πριν το αφήσεις χωρίς επίβλεψη

Στα πρώτα logs, θα δεις τη λίστα λιγκών (tier1/tier2/κύπελλα/διεθνή) και τη
λίστα bookmakers. Μετά τον πρώτο κύκλο markets, θα δεις τις γραμμές:
- **"Διαγνωστικό markets"** — πόσες προβλέψεις υπολογίστηκαν ανά τύπο
- **"Στάλθηκαν ανά κανάλι"** — πόσες πέρασαν το φίλτρο και στάλθηκαν
